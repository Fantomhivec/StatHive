# Команда: установка и первый вход

Лист «Пользователи» читает/пишет **Service Account** (участникам Drive writer на эту таблицу **не** выдаётся). Скрипты и калькулятор — **user OAuth**. OAuth Desktop JSON вставляет **Admin** при setup и публикует на лист **TeamOAuth** той же таблицы; в код UR3 OAuth **не** входит. SA JSON — у Admin локально и внутри UR3 под **паролем кода**.

Ключи WB/Ozon — файл формата `.env` **рядом с приложением** (имя любое: `.env`, `keys.env`, `cab.env`, …; содержимое `KEY=VALUE`). Копии в AppData удаляются. Участникам файл **не передают**; в UI — «Выбрать .env» (диалог в папке exe). Экспорт — plaintext-бэкап на доверенный носитель.

## Admin

1. Установите приложение.
2. «Я Admin» → вставьте OAuth Desktop JSON → Google → создайте команду.
   - В поле названия укажите **имя команды** (например `URI`) — в Drive таблица будет **`URI - Команда`**.
   - На экране Admin инструкция по OAuth **всегда** на экране; если client уже сохранён — текущий client и внизу **«Новый OAuth»**.
   - Кратко создать клиент: [Google Cloud Console](https://console.cloud.google.com/) → проект → OAuth consent screen (Application name) → включить **Sheets API** и **Drive API** → Credentials → OAuth client ID → **Desktop app** → Download JSON.
   - Redirect loopback StatHive: `http://localhost:8765/`.
   - Scopes обычной работы: `spreadsheets`, `drive`, `drive.file`, `userinfo.email`, `openid`. Scope `cloud-platform` нужен **только** если создаёте Service Account кнопкой из приложения.
3. Вкладка **Пользователи**:
    - **Название команды** — Admin может переименовать таблицу/команду (Drive + локальный конфиг); затем заново **«Скопировать код команды»** для новых участников;
    - **Service Account** — JSON вручную (без `cloud-platform`) или «Создать для этой таблицы» (запросит Cloud-права; SA только на таблицу этой команды). При утечке ключа/кода — **«Заменить Service Account»**, затем новый код всем участникам;
    - **OAuth команды** — опубликовать локальный Desktop JSON на лист TeamOAuth; выдать гранты логинам (по умолчанию участники без доступа; **builtin Admin всегда допущен**);
    - **Пресеты** — создайте пресеты прав (название + отдельные скрипты / калькулятор);
    - **Открыть таблицу** — Google Sheets команды (листы «Пользователи», «Пресеты», TeamOAuth) — только для Admin;
    - пригласите участников (логин, пароль, Google email, **обязательный пресет**) — **без** шаринга таблицы пользователю;
    - **Скопировать код команды** → задайте **пароль кода** (мин. 8) → передайте участнику код UR3, пароль кода, логин/пароль входа.
4. В titlebar после входа: **`команда - пользователь`** (например `URI - Макс`).
5. Пресеты пишутся в лист `Пресеты`; у участника в `AccessLevel` — id выбранного пресета. Admin — отдельное значение, не пресет.

При входе логин и пароль **Admin и участников** сверяются с листом «Пользователи» через Service Account. Локальный OAuth Desktop на входе **не** обязателен.

Код команды **UR3** содержит workspace id/title и **Service Account** (зашифрован паролем кода). OAuth Desktop в коде **нет**.

Если ранее участнику уже выдали Drive writer на таблицу команды — снимите доступ вручную в Google Drive → «Управление доступом».

### Несколько команд на одном ПК

Профили лежат в `%AppData%/StatHive/teams/{id}/` (oauth, SA, token, session, workspace) + индекс `teams_index.json`. Если раньше файлы лежали прямо в корне AppData, при первом запуске они переедут в первый профиль команды.

**Экран входа (хаб)**, если есть хотя бы одна сохранённая команда:

1. **Войти в существующую** — список → email / логин / пароль.
2. **Ввести код команды** — UR3 + пароль кода (добавить или обновить профиль).
3. **Настроить новый OAuth** — Admin: новый слот → JSON → Google → новая команда.

Ручное удаление AppData для «с нуля» не нужно.

**Профиль → сохранённые команды:** переключение на другую команду.

- Цель = **Admin** (роль в этой команде / команда создана локально): откроется браузер Google (обновить user OAuth под client этой команды).
- Цель = **участник**: без браузера; при валидной `session.json` команды сессия восстановится, иначе форма входа.

Проверка: в Профиле — название/id активной команды; после switch titlebar показывает новую пару `команда - пользователь`.

### «Доступ к приложению StatHive» (Google)

Это **не** название команды/Sheets. Так Google показывает **Application name** OAuth consent screen у Desktop-клиента.

Чтобы сменить надпись: [Google Cloud Console](https://console.cloud.google.com/) → APIs & Services → OAuth consent screen → Application name (или создайте новый OAuth Desktop client в нужном проекте и вставьте новый JSON Admin’у). Название таблицы в Drive на это не влияет.

## Участник

1. Установите тот же бинарник.
2. «Я участник» → вставьте **код UR3** и **пароль кода** один раз (новый код после смены SA/пароля у Admin).
3. После кода: **«Добро пожаловать в команду …»** и поля Google email / логин / пароль.
4. Дальше каждый запуск: те же поля. Email должен совпадать с тем, что указал Admin при приглашении. Браузер Google у обычного участника при входе **не** открывается — лист «Пользователи» читается через Service Account из UR3.
5. Google OAuth (user token / командный Desktop client) нужен, если в пресете есть скрипты/таблицы без пометки «без OAuth»:
   - если Admin выдал грант TeamOAuth — Desktop client подтягивается при входе; на «Проверка ключей» — **Проверить подключение** (браузер consent);
   - без гранта кнопка не показывается, а локальный `oauth_client.json` при таком логине **удаляется** (потом снова создаётся auto-pull при логине с грантом);
   - вставку Desktop JSON делает **только main Admin** (не keysCheck).

Права на скрипты, калькулятор, вкладки «Пользователи» / «Проверка ключей» и режимы с/без своего Google OAuth — см. **[USER_ACCESS.md](./USER_ACCESS.md)** (роли, пресет, `HasOauth`, грант TeamOAuth, `memberOk`, tables view-only).

Кратко: права берутся из **пресета** (`AccessLevel` = id пресета). Если в пресете нет доступных скриптов (с учётом OAuth/`memberOk`) — вкладки «Шаблоны» нет; режим калькулятора — если в пресете включены флаги calc.

## Что передать участнику

| Что | Откуда |
|-----|--------|
| Установщик | GitHub Releases |
| Код команды (`UR3.…`) | Пользователи → «Скопировать код команды» |
| Пароль кода | тот же диалог (не в коде; запомните/передайте отдельно) |
| Логин и пароль | форма приглашения |

Сессия и токены — в AppData на каждом ПК (at-rest). См. [SECURITY_CREDENTIALS.md](./SECURITY_CREDENTIALS.md).

Устаревший `UR2.…` приложение отклоняет — нужен новый UR3 от Admin.
